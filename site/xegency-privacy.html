Xegency privacy policy

Last updated: 3 November 2026

What this app is

Xegency Autopilot is an internal tool run by Xegency (xegency.com), an AI-native software studio in Dhaka, Bangladesh. Xegency uses it to publish its own posts to its own accounts on Facebook, Instagram, Threads, YouTube, LinkedIn, Pinterest and other platforms. Nobody else signs in to it.

What data it uses

The app only stores the access tokens Xegency grants when connecting its own accounts. It uses them only to publish Xegency's content and to check that the connections still work. Tokens are stored encrypted, as secrets in a private configuration.

The app doesn't collect, store, sell or share personal data about anyone else. It doesn't read followers' data, messages or other people's content, and it uses no tracking or analytics.

Deleting data

Xegency can revoke the app's access at any time from each platform's settings, which makes the stored tokens useless. To ask a question or request deletion, email rifat@xegency.com.
